📚 Documentação de Sinais (Assinaturas)

Você pode usar os sinais básicos ou aplicar a Sobrecarga de Intervalo (t, a, b) para limitar qualquer função.

u(t, a, b): Degrau unitário. Vale 1 para t ≥ 0.

rect(t, a, b): Pulso retangular. Padrão: [-0.5, 0.5].

tri(t, a, b): Pulso triangular. Padrão: [-1, 1].

sinc(t, a, b): Seno cardinal sin(πt)/(πt).

ramp(t, a, b): Rampa unitária t · u(t).

e(t, a, b): Exponencial natural (et).

sin(t, a, b) / cos(t, a, b): Funções trigonométricas.

dirac(t): Impulso de Dirac (Delta δ). Fixo em t=0.

dublet(t, a, b): Dupleto (Derivada do impulso).

pulse(t, start, end): Pulso genérico entre limites.

inf / minf: Limites dinâmicos do grid atual.

💡 Exemplo de Expressão Complexa

2 * rect(t, -5, 3) + sinc(t, 0, inf)

Isso cria um pulso de amplitude 2 entre -5 e 3, somado a uma função Sinc que só começa no zero e vai até o infinito visual.

Constantes Dinâmicas

Use inf e minf para representar os limites atuais da sua visualização. Útil para criar sinais que acompanham o zoom do Lab.

Domínio Discreto [n]

As mesmas funções funcionam para n. O intervalo a, b é arredondado para o inteiro mais próximo automaticamente.

Sistemas em Série (Cascata)

Representado pela multiplicação ✖️. No domínio do tempo, a resposta equivalente é a convolução:

h_eq(t) = h1(t) * h2(t)

Sistemas em Paralelo

Representado pela soma ➕. A resposta equivalente é a soma algébrica das respostas individuais:

h_eq(t) = h1(t) + h2(t)
⚠️ Nota Acadêmica: A ordem dos blocos em série não altera o resultado se os sistemas forem Lineares e Invariantes no Tempo (SLIT).

Linearidade

Um sistema é linear se satisfaz a Superposição e Homogeneidade. Se você dobrar a entrada, a saída deve dobrar.

Invariância no Tempo

O comportamento do sistema não muda com o tempo. Se x(t) -> y(t), então x(t-τ) -> y(t-τ).

Causalidade

O sistema é causal se a saída depende apenas de valores atuais ou passados da entrada. Sistemas que "preveem" o futuro são não-causais.

Estabilidade (BIBO)

Entradas limitadas (Bounded Input) devem gerar saídas limitadas (Bounded Output). Se o sinal explode para infinito, é instável.

Dica de Prova: Memória

Sistemas sem memória dependem apenas do instante t atual. Exemplos: resistores, amplificadores simples. Sistemas com capacitores ou indutores possuem memória pois armazenam energia (estado passado).
